# Digivahan Android App 🚗📱

**Digivahan Android App** is a mobile-first platform developed by **Digivahan Digital India Pvt. Ltd.** to provide vehicle-related services such as vehicle details, challans, PUC, and insurance information in a convenient and secure way.

## Features ✨
- Check vehicle details by number
- View RC, PUC, and Insurance documents
- QR-based vehicle safety system
- User-friendly interface with fast navigation
- Secure and reliable service
